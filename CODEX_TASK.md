# Project handoff

Margin Maker v0.3.0 is feature-complete for personal use and source publication.
Read [AGENTS.md](AGENTS.md), [README.md](README.md), and [TESTING.md](TESTING.md).

The user accepted the documented `/ActualText` limitation. Do not pursue another
safeguard or PDF-engine change as part of finalizing this version. The detailed
investigation is preserved in [ACTUALTEXT_SAFEGUARD.md](ACTUALTEXT_SAFEGUARD.md);
no detection prototype is included in the application.

Preserve history, baseline `v0.2.0`, local `v0.3.0`, and existing app/ZIP artifacts.
Build into a fresh output directory. Source hosting, pushing, publication, or
repository visibility changes require a separate user instruction. Developer ID
signing, notarization, paid services, and public binary distribution are outside
the release scope. See [RELEASE_CHECKLIST.md](RELEASE_CHECKLIST.md) for the record.
